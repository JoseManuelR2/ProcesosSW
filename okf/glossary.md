# Términos

| Término | Significado |
|---|---|
| **pista / track** | Una canción (no aplica; término heredado). |
| **cuenta** | Usuario registrado en el sistema. |
| **rol** | `usuario` o `administrador`. |
| **partida** | Una sesión de Maze Duel. |
| **laberinto** | Grid procedural generado por semilla. |
| **programa** | Árbol JSON de bloques que controla el robot. |
| **CAD** | Capa de acceso a datos (memoria o Mongo). |
| **Socket.IO** | Canal de tiempo real para el juego. |
